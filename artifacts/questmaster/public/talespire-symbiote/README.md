# Aetheria VTT pour TaleSpire

Ouvrez vos fiches Aetheria VTT dans TaleSpire et modifiez-les : chaque changement est enregistré sur le site, et inversement.

Installation manuelle : copier ce dossier dans le répertoire des Symbiotes de TaleSpire, puis l'activer dans le panneau Symbiotes.
Connexion : « Se connecter avec mon compte » ou « Code de liaison ». Aucune clé secrète n'est stockée dans ce module.
